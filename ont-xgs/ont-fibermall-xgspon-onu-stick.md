# Hardware Specifications

|                  |                                                                    |
| ---------------- | ------------------------------------------------------------------ |
| Vendor/Brand     | FiberMall                                                          |
| Model            | XGSPON-ONU-STICK                                                   |
| ODM              | [BFW Solutions WAS-110](/xgs/ont-bfw-solutions-was-110)            |
| Chipset          | MaxLinear PRX126                                                   |
| Flash            | 128 MB SPI NAND (Winbond W25N01GV)                                 |
| RAM              | 1 GB LPDDR3 (Nanya NT6CL256M32AM)                                  |
| CPU              | MIPS interAptiv (34Kc family)                                      |
| CPU Clock        | 400MHz                                                             |
| SFP interfaces   | 10GBASE-R (SFI/XFI)                                                |
| Optics           | SC/APC (Tx 1270 nm / Rx 1577 nm)                                   |
| IP address       | 192.168.11.1                                                       |
| Web Gui          | ✅ HTTPS                                                           |
| SSH              | ✅                                                                 |
| Serial           | ✅ on SFP (Rx pin 7, Tx pin 2)                                     |
| Serial baud      | 115200                                                             |
| Serial encoding  | 8-N-1                                                              |
| Form Factor      | miniONT SFP+                                                       |

This stick is a rebrand of the [BFW Solutions WAS-110](/xgs/ont-bfw-solutions-was-110). It ships with an 8311 community firmware fork. See the WAS-110 page for full details on hardware, partitions, EEPROM, and credentials.

::: warning Warning
The 8311 firmware fork shipped by FiberMall is **not** supported by the 8311 community. Ask FiberMall for support or [install the official 8311 community firmware](https://pon.wiki/guides/install-the-8311-community-firmware-on-the-was-110/).
:::
