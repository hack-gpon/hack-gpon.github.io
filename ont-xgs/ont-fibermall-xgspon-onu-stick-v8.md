# Hardware Specifications

|                  |                                                                    |
| ---------------- | ------------------------------------------------------------------ |
| Vendor/Brand     | FiberMall                                                          |
| Model            | XGSPON-ONU-STICK-V8                                                |
| ODM              | [Potron Technology X-ONU-SFPP](/xgs/ont-potron-technology-x-onu-sfpp) |
| Chipset          | MaxLinear PRX126                                                   |
| Flash            | 128 MB SPI NAND (Winbond W25N01GV)                                 |
| RAM              | 1 GB (Rayson RS256M32LD3D1LMZ)                                     |
| CPU              | MIPS interAptiv (34Kc family)                                      |
| CPU Clock        | 400MHz                                                             |
| SFP interfaces   | 10GBASE-R (SFI/XFI)                                                |
| Optics           | SC/UPC or SC/APC (Tx 1270 nm / Rx 1577 nm), laser driver MACOM M02181 |
| IP address       | 192.168.1.1                                                        |
| Web Gui          | ❌ (OEM firmware)                                                  |
| SSH              | ✅                                                                 |
| Serial           | ✅ on SFP (Rx pin 7, Tx pin 2)                                     |
| Serial baud      | 115200                                                             |
| Serial encoding  | 8-N-1                                                              |
| Form Factor      | miniONT SFP+                                                       |

This stick is a rebrand of the [Potron Technology X-ONU-SFPP](/xgs/ont-potron-technology-x-onu-sfpp). It ships with an 8311 community firmware fork. See the X-ONU-SFPP page for full details on hardware, partitions, EEPROM, and credentials.

::: warning Warning
The 8311 firmware fork shipped by FiberMall is **not** supported by the 8311 community. Ask FiberMall for support or [install the official 8311 community firmware](https://pon.wiki/guides/install-the-8311-community-firmware-on-the-was-110/#supplementary-upgrades).
:::
