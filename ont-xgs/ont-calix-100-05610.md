### Shell credentials (HALNy HLX-SFPX)

::: info Info
On firmware **≤ V7.0.5** the administrator password is dynamically generated: it is `9k0J$5JKJPr(F@aL` followed by the last 3 octets of the MAC address in lowercase hexadecimal (e.g. `9k0J$5JKJPr(F@aLabcdef`).

On firmware **≥ V7.0.6** the password is static.
:::

| Firmware   | Username | Password            |
| ---------- | -------- | ------------------- |
| ≥ V7.0.6   | `admin`  | `9k0J$5JKJPr(F@aL`  |
| ≤ V7.0.5   | `admin`  | `9k0J$5JKJPr(F@aL` + last 3 MAC octets |
