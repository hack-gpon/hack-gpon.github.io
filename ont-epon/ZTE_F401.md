The ZTE F401 is a bridge type EPON ONT (1G-EPON, 1.25 Gbps symmetric, IEEE 802.3ah) with one 10/100/1000Base-T Ethernet port.

::: warning
The F401 is also sold in G/EPON (xPON) variants: check the label and the firmware of the unit before using it on a GPON network. For the GPON ZTE ONT with one GE port see the [ZTE F601](/ont-zte-f601).
:::
